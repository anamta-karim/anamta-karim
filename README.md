My work so far spans NLP, computer vision, and generative AI, alongside data analysis and machine learning. I'm particularly drawn to problems where working with data and building reliable systems meet.

## Featured Projects

### [SkinWise](https://github.com/anamta-karim/SkinWise)
**AI-powered skincare intelligence platform**

A skincare platform that combines ingredient analysis, personalized routines, and ethical product screening. It uses semantic matching to connect ingredient names and synonyms, OCR to extract information from product labels, and an LLM to support personalized analysis.

`Python` `Flask` `Sentence Transformers` `EasyOCR` `Groq LLM`

### Retinal Clinical Report Generation
**In progress · Vision-language models**

Exploring the generation of clinical descriptions from retinal fundus images using parameter-efficient fine-tuning of pretrained vision-language models. The work involves building a reproducible training pipeline under limited GPU memory and evaluating generated reports against established baselines.

`Python` `PyTorch` `Hugging Face Transformers` `PEFT/LoRA`
