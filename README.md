## About

My work so far spans NLP, computer vision, and generative AI, alongside data analysis and machine learning. I'm particularly drawn to problems where working with data and building reliable systems meet.

## Featured Projects

### [SkinWise](https://github.com/anamta-karim/SkinWise)
**AI-powered skincare intelligence platform**

A skincare platform that combines ingredient analysis, personalized routines, and ethical product screening. It uses semantic matching to connect ingredient names and synonyms, OCR to extract information from product labels, and an LLM to support personalized analysis.

`Python` `Flask` `Sentence Transformers` `EasyOCR` `Groq LLM`

### [Layoffs Data Analysis](https://github.com/anamta-karim/Layoffs-Data-Analysis)
**SQL-based exploratory data analysis**

Analyzed company layoffs from March 2020 to March 2023 using MySQL. Cleaned and standardized the dataset, investigated missing values and duplicates, and explored layoff patterns across companies, industries, countries, and time using aggregations, CTEs, window functions, rolling totals, and yearly rankings.

`MySQL` `SQL` `Data Cleaning` `EDA` `CTEs` `Window Functions`

### [Data Professionals Survey Insights](https://github.com/anamta-karim/data-professionals-survey-insights)
**Interactive Power BI dashboard**

Cleaned and transformed survey data using Power Query, then built an interactive Power BI dashboard to explore salary trends across job titles, programming language preferences, respondent demographics, perceived barriers to entering data careers, and work-life balance and salary satisfaction.

`Power BI` `Power Query` `Data Cleaning` `Data Visualization` `Dashboard`

### [Seattle Airbnb Market Analysis](https://github.com/anamta-karim/Seattle-Airbnb-Market-Analysis)
**Interactive Tableau dashboard**

Explored Seattle Airbnb listings using Tableau and Excel to analyze average prices by bedroom count, pricing differences across ZIP codes, listing distribution, and weekly calendar price trends in 2016. Built an interactive dashboard to help prospective hosts understand historical rental market patterns.

`Tableau` `Excel` `Data Visualization` `Market Analysis` `Dashboard`

### [Bike Sales Dashboard](https://github.com/anamta-karim/bike-sales-dashboard)
**Interactive Excel dashboard**

Cleaned and analyzed bike buyer data in Excel by removing duplicate records, standardizing customer attributes, and grouping ages into brackets. Built PivotTables, charts, and slicers to explore average income and bike purchase patterns by gender, age group, and commute distance.

`Microsoft Excel` `Data Cleaning` `PivotTables` `PivotCharts` `Slicers` `Dashboard`

### Retinal Clinical Report Generation
**In progress · Vision-language models**

Exploring the generation of clinical descriptions from retinal fundus images using parameter-efficient fine-tuning of pretrained vision-language models. The work involves building a reproducible training pipeline under limited GPU memory and evaluating generated reports against established baselines.

`Python` `PyTorch` `Hugging Face Transformers` `PEFT/LoRA`
